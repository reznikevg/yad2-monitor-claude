# 🏠 מוניטור יד 2 בענן + בוט שליטה בטלגרם (100% API)

מערכת סריקה אוטומטית בענן (GitHub Actions) שסורקת את ה-API הפנימי של יד 2 (`gw.yad2.co.il/realestate-feed/rent/map`), מזהה דירות חדשות או שינויי מחיר/פרטים, ושולחת התרעות לטלגרם עם **לוח בקרה אינטראקטיבי מלא (כפתורים ופקודות)**.

---

## ✨ מה שודרג במערכת?

1. **100% מבוסס API (ללא דפדפן Playwright):**
   - הסריקה מתבצעת ישירות מול ה-API של יד 2 באמצעות `curl_cffi>=0.17.0` עם רוטציית פרופילי TLS עדכניים (`chrome131`, `chrome124`, `safari17_0`, `edge101`) והתאמת כותרות מדויקת לעקיפת חסימת ה-Radware Bot Manager.
   - זמן ריצה של הסריקה ירד מ-**6.5 דקות** ל-**שנייה אחת בלבד**.
2. **שליטה מלאה מהטלגרם (כפתורים + פקודות):**
   - כל ההגדרות נשמרות דינמית בקובץ [`state/config.json`](state/config.json) ומסתנכרנות אוטומטית לגיט.
   - תפריט כפתורים אינטראקטיבי לביצוע סריקה מיידית, צפייה בסטטוס, שינוי תקציב מקסימלי, שינוי מינימום חדרים, השהיה/הפעלה של חיפושים, והוספת חיפושים חדשים.
3. **המרת לינקים אוטומטית:**
   - כדי להוסיף חיפוש חדש לא צריך יותר לפתוח Network Tab בדפדפן — פשוט שולחים לבוט בטלגרם קישור רגיל מחיפוש באתר יד 2 (`https://www.yad2.co.il/realestate/rent/...`) והבוט ממיר אותו אוטומטית לקריאת API של `gw.yad2.co.il`.
4. **חלוקת הודעות חכמה וסינון דירות פעילות:**
   - הודעות ארוכות מחולקות אוטומטית למקטעים כדי לעמוד במגבלת 4,096 התווים של טלגרם.
   - דירות שירדו מהאתר מסומנות כ-`active: false` כך שסיכום הדירות היומי (`/summary`) מציג רק דירות **פעילות כרגע** (תוך שמירת ההיסטוריה למניעת התרעות כפולות).

---

## 🤖 פקודות וכפתורים בטלגרם

ניתן להשתמש בכפתורים המובנים בהודעות הבוט או לשלוח את הפקודות הבאות בצ׳אט:

| פקודה | פעולה |
|---|---|
| `/menu` או `/start` | פתיחת לוח הבקרה הראשי עם כפתורים אינטראקטיביים |
| `/scan` | ביצוע סריקת API מיידית של כל החיפושים הפעילים |
| `/status` | הצגת מצב המערכת, מספר דירות פעילות בכל חיפוש, ומועד סריקה אחרון |
| `/summary` | שליחת רשימת כל הדירות הפעילות כרגע (או `/summary A` לחיפוש ספציפי) |
| `/searches` | תפריט ניהול חיפושים (שינוי מחיר, חדרים, השהיה/הפעלה, מחיקה) |
| `/add שם \| לינק` | הוספת חיפוש חדש מקישור של יד 2 (אפשר גם פשוט להדביק לינק בצ׳אט) |
| `/setprice A 11000` | עדכון מחיר מקסימלי לחיפוש `A` |
| `/setrooms A 3.5` | עדכון מינימום חדרים לחיפוש `A` |
| `/pause` / `/resume` | השהיה או הפעלה מחדש של כל הסריקות |

## 📁 מבנה הפרויקט

* [`yad2_monitor.py`](yad2_monitor.py) — סקריפט ה-API המרכזי ומנוע הבוט האינטראקטיבי לטלגרם.
* [`state/config.json`](state/config.json) — הגדרות המערכת והחיפושים (מתעדכן אוטומטית גם מהטלגרם).
* [`state/state_tlv.json`](state/state_tlv.json) / [`state/state_center_sharon.json`](state/state_center_sharon.json) — מאגר המודעות והסטטוס של כל מקור חיפוש.
* [`.github/workflows/monitor.yml`](.github/workflows/monitor.yml) — תהליך ה-GitHub Actions בענן.
* [`noop_playwright/`](noop_playwright/) — חבילה מקומית קלה שמדלגת על התקנת הדפדפן ב-CI לחיסכון בזמן ריצה.
